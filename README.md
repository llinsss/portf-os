# llins · Desktop Portfolio

An interactive macOS-style desktop portfolio built from public projects on [@llinsss](https://github.com/llinsss).

## Preview

The site is designed for GitHub Pages at:

https://llinsss.github.io/portf-os/

## Deploy with GitHub Pages

The workflow in [.github/workflows/deploy-pages.yml](.github/workflows/deploy-pages.yml) publishes the root static site when main changes and supports manual runs.

For the first deployment, open Settings → Pages and set Build and deployment → Source to GitHub Actions. Then open Actions → Deploy to GitHub Pages → Run workflow. Later updates to main deploy automatically.

## Source

The complete static page is in [index.html](index.html). It has no package install or build step.
